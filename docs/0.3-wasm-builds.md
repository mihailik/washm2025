## WASM Build targets

This project builds the shell binary at the crate root. To build for native and WASM targets:

- Native (host): `cargo build` — builds the default `washm` executable.
- WASI: `cargo build --target wasm32-wasi` — produces `target/wasm32-wasi/debug/washm.wasm`.
- Unknown (where you plan to do JS bundling): `cargo build --target wasm32-unknown-unknown` — can be used when integrating with JS toolchains.

We provide npm scripts to run them from a consistent place in development (Windows `cmd` commands are in `scripts/`):

`npm run build:rust:native` — builds the native binary.
`npm run build:rust:wasm-wasi` — builds wasm32-wasi (allowed to fail for now).
`npm run build:rust:wasm-unknown` — builds wasm32-unknown-unknown (allowed to fail for now).

The `examples/monolith` includes a small README showing how to run the wasm binary under Wasmtime. The `scripts/build-wasm.cmd` helper will install targets and try both wasm builds while treating failure as a soft error.
