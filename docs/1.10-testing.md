## Detailed Plan: Comprehensive WASM Test Harness (`washm_mock.js`)

### Overview
Create a test harness that executes the **real washm.js** in mocked environments (Node.js or browser) to test both code paths. Instead of reimplementing WASI and bootstrap logic, the harness provides minimal mocked APIs and evaluates washm.js in a controlled scope. This approach tests the actual production code while maintaining complete isolation. The harness supports two modes: **Node mode** (tests real Node.js path with mocked WASI) and **Browser mode** (tests real browser path with mocked DOM/xterm).

---

### File Structure
- **`test/washm_mock.js`** — Single-file harness module containing:
  - Shared components (stream buffers, mock modules)
  - Node preloader (~500 LOC) — complete WASI mock + eval washm.js in Node scope
  - Browser preloader (~300 LOC) — DOM/xterm mocks + eval washm.js in browser scope
  - Unified `washEnvironment(opts)` export with `mode` parameter
- **`test/smoke.test.js`** — Smoke test validating harness loads
- **`test/streams.test.js`** — Unit tests for stream buffer infrastructure
- **`test/node-basic.test.js`** — Basic Node mode integration tests
- **`test/commands.test.js`** — Command execution tests (pwd, echo, exit)
- **`test/browser.test.js`** — Browser mode and dual-mode comparison tests
- **Single test command:** `npm test` runs all test files with Node's built-in test runner

### Step 2: Node Preloader (section in `washm_mock.js`)

The Node preloader creates a complete WASI mock and evaluates real washm.js in a Node-like scope. **Key insight:** We must implement all WASI syscalls that Rust might call, but the implementation can be simpler than the current mock - no complex FileDescriptorTable, cleaner fd tracking, and the VFS paths (`/dev/host/eval/`) flow through these syscalls naturally.

**Complete MockWASI class (~500 LOC total):**
```js
function nodePreloader(opts, streams) {
  let collectEvalJS = '';
  let exitCode = null;
  const fdTable = new Map(); // Track open file descriptors
  let nextFd = 4; // FDs 0,1,2,3 reserved
  
  class MockWASI {
    constructor(wasiOpts) {
      this.wasiImport = {
        // Args and environment
        args_sizes_get: (argc, argvBufSize) => { /* return argv counts */ },
        args_get: (argv, argvBuf) => { /* write argv strings */ },
        environ_sizes_get: (environc, environBufSize) => { /* return env counts */ },
        environ_get: (environ, environBuf) => { /* write env strings */ },
        
        // Standard I/O
        fd_write: (fd, iovs, iovsLen, nwritten) => {
          if (fd === 20251219) { // Bootstrap FD
            collectEvalJS += readIovs(iovs, iovsLen);
            return 0;
          }
          if (fd === 1) { streams.stdout.write(readIovs(iovs, iovsLen)); return 0; }
          if (fd === 2) { streams.stderr.write(readIovs(iovs, iovsLen)); return 0; }
          // Handle VFS writes (e.g., /dev/host/eval/<cookie>.js)
          const fdInfo = fdTable.get(fd);
          if (fdInfo) {
            fdInfo.buffer.push(readIovs(iovs, iovsLen));
            return 0;
          }
          return 8; // EBADF
        },
        
        fd_read: (fd, iovs, iovsLen, nread) => {
          if (fd === 0) { /* read from streams.stdin */ }
          // Handle VFS reads (e.g., /dev/host/eval/<cookie>.json)
          const fdInfo = fdTable.get(fd);
          if (fdInfo && fdInfo.buffer) {
            /* write from buffer to iovs */
            return 0;
          }
          return 8; // EBADF
        },
        
        fd_close: (fd) => {
          if (fd === 20251219) { // Bootstrap FD
            // Evaluate accumulated JS in mocked scope
            const process = mockProcess;
            const require = mockRequire;
            const globalThis = mockGlobalThis;
            const __dirname = '/mock';
            eval(collectEvalJS); // Runs protocol.js, then bridges
            collectEvalJS = '';
            return 0;
          }
          fdTable.delete(fd);
          return 0;
        },
        
        // Preopens (directory mappings)
        fd_prestat_get: (fd, bufPtr) => {
          if (fd === 3) { /* return root dir "/" */ }
          return 8; // EBADF
        },
        fd_prestat_dir_name: (fd, pathPtr, pathLen) => {
          if (fd === 3) { /* write "/" */ }
          return 8;
        },
        
        // File operations (for VFS paths like /dev/host/eval/<cookie>.js)
        path_open: (fd, dirflags, path, pathLen, oflags, fsRightsBase, fsRightsInheriting, fdflags, fdPtr) => {
          const pathStr = readString(path, pathLen);
          const newFd = nextFd++;
          fdTable.set(newFd, { path: pathStr, buffer: [] });
          writeU32(fdPtr, newFd);
          return 0;
        },
        
        path_filestat_get: (fd, flags, path, pathLen, bufPtr) => {
          const pathStr = readString(path, pathLen);
          // Check if path is cwd (for std::env::set_current_dir)
          if (pathStr === opts.cwd || pathStr === '.' || pathStr === '/') {
            writeFileStat(bufPtr, { filetype: 3, size: 0 }); // Directory
            return 0;
          }
          // Check if path exists in VFS
          if (fdTable.has(pathStr)) {
            writeFileStat(bufPtr, { filetype: 4, size: 0 }); // Regular file
            return 0;
          }
          return 44; // ENOENT
        },
        
        fd_filestat_get: (fd, bufPtr) => {
          if (fd <= 2) { // stdin/stdout/stderr
            writeFileStat(bufPtr, { filetype: 2, size: 0 }); // Character device
            return 0;
          }
          const fdInfo = fdTable.get(fd);
          if (fdInfo) {
            writeFileStat(bufPtr, { filetype: 4, size: fdInfo.buffer.join('').length });
            return 0;
          }
          return 8; // EBADF
        },
        
        fd_seek: (fd, offset, whence, newOffsetPtr) => {
          // Simple stub - VFS doesn't need seeking
          writeU64(newOffsetPtr, 0);
          return 0;
        },
        
        fd_fdstat_get: (fd, bufPtr) => {
          if (fd <= 2) { /* write character device stats */ return 0; }
          if (fdTable.has(fd)) { /* write regular file stats */ return 0; }
          return 8; // EBADF
        },
        
        // Process control
        proc_exit: (code) => { exitCode = code; },
        
        // Time and randomness
        clock_time_get: (clockId, precision, time) => { /* return mock time */ },
        random_get: (buf, bufLen) => { /* fill with mock random data */ },
        
        // Polling (stub)
        poll_oneoff: (in_, out, nsubscriptions, neventsPtr) => { return 0; },
        
        // Additional syscalls that Rust might call
        fd_advise: () => 0,
        fd_allocate: () => 0,
        fd_datasync: () => 0,
        fd_sync: () => 0,
        fd_pread: () => 28, // ENOSYS
        fd_pwrite: () => 28,
        fd_readdir: () => 28,
        fd_renumber: () => 28,
        fd_tell: () => 28,
        path_create_directory: () => 0, // Stub
        path_filestat_set_times: () => 0,
        path_link: () => 28,
        path_readlink: () => 28,
        path_remove_directory: () => 0,
        path_rename: () => 0,
        path_symlink: () => 28,
        path_unlink_file: () => 0,
        sched_yield: () => 0,
        sock_recv: () => 28,
        sock_send: () => 28,
        sock_shutdown: () => 28,
      };
    }
    
    start(instance) {
      instance.exports._start();
    }
  }
  
  // Create mocked scope
  const mockProcess = createMockProcess(opts, streams);
  const mockOs = createMockOsModule(opts);
  const mockFs = createMockFsModule();
  const mockTty = createMockTtyModule();
  const mockChildProcess = createMockChildProcessModule();
  const mockRequire = createMockRequire(mockFs, mockOs, mockTty, mockChildProcess);
  const mockGlobalThis = { mounted: { washm: { start_pwd: opts.cwd || '/' } } };
  
  // Eval real washm.js in this scope
  const washmJsCode = actualFs.readFileSync('./washm.js', 'utf8');
  const __dirname = '/mock';
  eval(washmJsCode); // washm.js detects isNode=true, runs mainNode()
  
  // washm.js has now loaded WASM and started it
  // Return handle to the running instance
  return { streams, exitCode: () => exitCode };
}
```

The browser preloader creates minimal browser API mocks and evaluates real washm.js in a browser-like scope. The real `fs.js` bridge (which runs during bootstrap) will use `sessionStorage` for file operations.

function browserPreloader(opts, streams) {
  // Mock sessionStorage (used by fs.js bridge)
  const storageMap = new Map();
  const sessionStorage = {

      this._buffer = [];

      streams.stdout.write(data); // Also capture for tests

    open(container) {}
    loadAddon(addon) {}
    // Test API
    _sendInput(data) { this._dataHandlers.forEach(h => h(data)); }
  }

  const window = {

    Terminal: MockTerminal

  const document = {

    getElementById: () => null
  };

  const washmJsCode = actualFs.readFileSync('./washm.js', 'utf8');

}

### Step 4: Unified API (section in `washm_mock.js`)

**Export `washEnvironment(opts)` function with mode selection:**
Returns an object with streams and washm loader. The API is identical for both modes.

Structure:
```js
export async function washEnvironment(opts = {}) {
  const mode = opts.mode || 'node'; // Default to node mode
  
  // Create streams (shared by both modes)
  const streams = {
    stdin: new MockStdin(),
    stdout: new MockStdout(),
    stderr: new MockStdout()
  };
  
  // Choose preloader based on mode
  let runtime;
  if (mode === 'node') {
    runtime = nodePreloader(opts, streams);
  } else if (mode === 'browser') {
    runtime = browserPreloader(opts, streams);
  } else {
    throw new Error(`Unknown mode: ${mode}. Use 'node' or 'browser'`);
  }
  
  return {
    streams,
    washm: async (argv = []) => {
      // washm.js has already been evaluated and WASM started
      // Return instance wrapper for test control
      return new WashmInstance(runtime, streams);
    }
  };
}
```

**Key differences from old approach:**

| Aspect | Old Approach | New Approach |
|--------|-------------|--------------|
| WASI implementation | ~1000 LOC custom | ~500 LOC complete (simpler tracking) |
| Bootstrap eval | Manual implementation | Real washm.js handles it |
| VFS | Custom implementation | Real protocol.js provides it |
| File operations | Complex FileDescriptorTable | Simple Map-based fd tracking |
| Code tested | Custom mock code | **Real production code** |
| Test modes | Node only | **Node + Browser** |

**Options supported:**
- `opts.mode` — `'node'` or `'browser'` (default: `'node'`)
- `opts.cwd` — initial working directory (default: `'/'`)
- `opts.env` — initial environment variables
- `opts.platform` — process.platform (node mode)
- `opts.arch` — process.arch (node mode)
- `opts.cpus` — navigator.hardwareConcurrency (browser mode)
- `opts.memory` — navigator.deviceMemory (browser mode)

### Step 5: I/O Interception (section in `washm_mock.js`)

The harness doesn't need to manually implement the eval VFS mechanism - **real washm.js already handles it via protocol.js**. We only need to intercept I/O at the boundaries for test control.

**Stream interception approach:**

**Node mode:**
- WASI `fd_write(FD 1)` → `streams.stdout.write()`
- WASI `fd_write(FD 2)` → `streams.stderr.write()`
- WASI `fd_read(FD 0)` → `streams.stdin.read()`
- Real protocol.js handles `/dev/host/` VFS (including eval)

**Browser mode:**
- `Terminal.write()` → intercept and copy to `streams.stdout`
- `Terminal.onData()` → provide handler that reads from `streams.stdin`
- Real fs.js bridge handles filesystem via sessionStorage
- Real protocol.js handles `/dev/host/` VFS (including eval)

**Test control APIs:**

Tests can interact with the running WASM through the stream buffers:
```js
// Send input
washm.streams.stdin.write('echo hello\n');

// Read output
const output = washm.streams.stdout.readAll();

// Check errors
const errors = washm.streams.stderr.readAll();
```

**Advanced: Override eval behavior (optional):**
If tests need to mock specific host eval calls, they can intercept by modifying `globalThis.mounted.eval` before WASM starts. However, this is rarely needed since the real eval bridge works correctly with the mocked environment.

### Step 9: Advanced Features

test('pwd output matches between modes', async () => {
