# In-process coreutils integration design

In order to integrate coreutils (and other in-process commands acting as out-of-process) int WASHM, we need a way to allocate the context per such command, run it within the same WASM module, and yet dedicate a separate stdio context (stdin/stdout/stderr) per command invocation.

We identified the macro system (uucore exports macros, ls uses them); my next step is to outline a precise plan to intercept prints via task-local storage using macro shadowing or a new streams module.

## Plan: Redirect ls prints via task-local storage ✅

### Strategy overview

Add a task-local stdio context that intercepts all output operations. Adjust the existing `show!`/`show_error!`/`show_warning!` macros and provide drop-in replacements for `print!`/`println!`/`eprintln!` that consult task-local storage. Minimal changes to `ls` source required.

### Steps (6 concrete steps) 🔧

#### 1. Add task-local stdio module to uucore
- **File:** `coreutils-fork/src/uucore/src/lib/mods/streams.rs`
- **Contents:**
  ```rust
  use std::cell::RefCell;
  use std::io::{self, Write};
  
  tokio::task_local! {
      static STDIO_STACK: RefCell<Vec<StdioContext>>;
  }
  
  pub struct StdioContext {
      pub out: Box<dyn Write + Send>,
      pub err: Box<dyn Write + Send>,
      pub is_tty: Option<bool>,
  }
  
  pub fn with_stdio<R>(ctx: StdioContext, f: impl FnOnce() -> R) -> R {
      STDIO_STACK.scope(RefCell::new(vec![ctx]), f)
  }
  
  pub fn with_stdout<R>(f: impl FnOnce(&mut dyn Write) -> io::Result<R>) -> io::Result<R> {
      STDIO_STACK.try_with(|stack| {
          if let Some(ctx) = stack.borrow_mut().last_mut() {
              f(&mut *ctx.out)
          } else {
              f(&mut io::stdout())
          }
      }).unwrap_or_else(|_| f(&mut io::stdout()))
  }
  
  pub fn with_stderr<R>(f: impl FnOnce(&mut dyn Write) -> io::Result<R>) -> io::Result<R> {
      STDIO_STACK.try_with(|stack| {
          if let Some(ctx) = stack.borrow_mut().last_mut() {
              f(&mut *ctx.err)
          } else {
              f(&mut io::stderr())
          }
      }).unwrap_or_else(|_| f(&mut io::stderr()))
  }
  
  pub fn current_is_tty() -> bool {
      STDIO_STACK.try_with(|stack| {
          stack.borrow().last()
              .and_then(|ctx| ctx.is_tty)
              .unwrap_or_else(|| io::stdout().is_terminal())
      }).unwrap_or_else(|_| io::stdout().is_terminal())
  }
  
  pub fn flush_stdout() -> io::Result<()> {
      with_stdout(|w| w.flush())
  }
  ```
- Export from mod.rs and lib.rs

### Further considerations ⚠️

1. **Macro shadowing caveat:** The std `print!`/`println!` macros cannot be shadowed at use-site. Options:
   - Use `scoped_print!`/`scoped_println!` explicitly (requires changing call sites in dired.rs)
   - OR: use a prelude module that imports scoped versions and add `#[allow(unused_macros)]` to suppress warnings about std macros

2. **BufWriter<Stdout> vs BufWriter<Box<dyn Write>>:** Need to change `ListState.out` type from `BufWriter<Stdout>` to `BufWriter<Box<dyn Write>>` or use a trait object wrapper

3. **Testing:** Add tests that:
   - Spawn a task with `tokio::task_local!` scope set
   - Call `ls` functions and verify output goes to captured buffer
   - Test wake/resume across `_continue` boundaries

4. **Async wrapping:** When calling from washm, wrap synchronous `ls` in:
   ```rust
   use uucore::streams::{StdioContext, with_stdio};
   
   let out_buf = Vec::new();
   let err_buf = Vec::new();
   let result = with_stdio(
       StdioContext {
           out: Box::new(out_buf.clone()),
           err: Box::new(err_buf.clone()),
           is_tty: Some(false),
       },
       || {
           // call ls uumain here
           uu_ls::uumain(args)
       }
   );
   ```
